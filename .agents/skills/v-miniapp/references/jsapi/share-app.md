# Share App API

API for sharing the mini-app.

---

## shareApp

**When to use:** Share the mini-app with other users.

**Basic usage (async):**
```tsx
await apisAsync.shareApp({
  // share options
})
```

**Key options:**
- Check API docs for share configuration (title, description, image, etc.)

**Note:** Opens native share dialog. User can share via various platforms.
